YBC 사무실 복합기

복합기(SINDOH D472) 인쇄 설정 안내

2026년 10월 15일 기준 · Windows PC / Mac 공통 안내 · PDF로 내려받기

1안내 개요

이제 복합기는 부문 비밀번호를 입력해야 인쇄와 복사가 됩니다. 비밀번호 없이 보낸 인쇄는 복합기에서 거부됩니다.

부문비밀번호
YBC-교육부담당자에게 별도 전달
YBC-기획운영팀담당자에게 별도 전달
  • 비밀번호는 외부에 공유하지 마세요.
  • Windows PC는 처음 한 번만 설정하면 이후 자동으로 적용됩니다. Mac은 인쇄할 때 저장해 둔 사전 설정을 골라야 합니다.
  • 복합기 앞에서 복사할 때는 패널에서 비밀번호를 입력합니다.

2시작 전 확인

반드시 신도 전용 드라이버로 연결된 프린터를 사용해야 합니다. Mac의 AirPrint나 Windows 기본(일반) 드라이버는 비밀번호를 보내지 못해 인쇄가 모두 거부됩니다.

프린터 모델SINDOH D472
프린터 주소(IP)192.168.1.200
드라이버 다운로드신도리코 D472 자료실
(sindoh.com → 지원 → 다운로드 → D472. 접속한 컴퓨터에 맞는 드라이버가 표시됩니다.)

드라이버 설치는 각자 컴퓨터에서 직접 진행합니다. 설치 중 컴퓨터 관리자 비밀번호를 물으면 입력하세요.

3Windows PC 설정 방법

한 번 설정하면 모든 프로그램에서 자동으로 비밀번호가 적용됩니다.

  1. 드라이버 설치 — 신도리코 D472 자료실에서 Windows용 드라이버(또는 원클릭 설치 sindoh Connect)를 받아 설치합니다.
  2. 기존 프린터 확인 — 설정 → Bluetooth 및 장치 → 프린터 및 스캐너에서 D472가 "Microsoft" 또는 일반 드라이버로 되어 있으면 제거하고, 신도 드라이버로 다시 추가합니다(주소 192.168.1.200).
  3. 부문 관리 켜기 — 프린터 선택 → 프린터 속성 → 구성(Configure) 탭에서 부문 관리를 체크합니다. 보이지 않으면 획득 설정(Obtain Settings)을 눌러 복합기 설정을 받아온 뒤 적용합니다.
  4. 비밀번호 입력 — 프린터 선택 → 인쇄 기본 설정 → 기본(Basic) 탭의 인증/부문 관리 버튼 → 부문 관리에 우리 부문 비밀번호를 입력하고 확인 → 적용합니다.
  5. 테스트 인쇄 — 아무 문서나 한 장 인쇄해 정상으로 나오는지 확인합니다.
반드시 "인쇄 기본 설정"에서 입력하세요. 인쇄 창에서만 입력하면 그 한 번만 적용됩니다.

4Mac 설정 방법

Mac은 비밀번호를 사전 설정으로 저장해 두고, 인쇄할 때마다 그 사전 설정을 골라야 합니다.

  1. 드라이버 설치 — 신도리코 D472 자료실에서 MAC Driver(macOS 11 이상용)를 받아 압축을 풀고 설치 파일(.pkg)을 실행합니다.
  2. 기존 프린터 제거 — 시스템 설정 → 프린터 및 스캐너에서 D472가 "AirPrint" 또는 "일반 PostScript"로 되어 있으면 선택 후 프린터 제거를 누릅니다.
  3. 프린터 추가 — 프린터, 스캐너 또는 팩스 추가 → 위쪽 IP 탭 → 주소 192.168.1.200, 프로토콜 LPD 또는 IPP, 이름 "SINDOH D472" → 사용에서 소프트웨어 선택을 눌러 D472(또는 SINDOH)를 검색해 고른 뒤 추가합니다.
  4. 비밀번호 입력 — 아무 문서나 열고 ⌘P → 프린터를 SINDOH D472로 선택(옵션이 안 보이면 세부사항 보기) → 가운데 메뉴를 출력 방법으로 변경 → 인증/부문 관리 버튼 → 부문 관리에 우리 부문 비밀번호를 입력하고 확인합니다.
  5. 사전 설정 저장 — 위쪽 사전 설정 메뉴 → 현재 설정을 사전 설정으로 저장 → "YBC-교육부"처럼 이름을 붙여 저장합니다.
  6. 테스트 인쇄 — 그대로 인쇄해 정상으로 나오는지 확인합니다.
다음부터 인쇄할 때는 사전 설정에서 저장한 이름을 고른 뒤 인쇄하세요. 고르지 않으면 인쇄가 거부됩니다. 프린터 설정의 "옵션" 탭에 부문 관리 항목이 없어도 정상이며, 4번처럼 인쇄 창에서 입력하면 됩니다.

5복합기에서 복사할 때

  1. 복합기 화면에 비밀번호 입력창이 나타나면 우리 부문 비밀번호를 입력하고 로그인을 누릅니다.
  2. 평소처럼 복사합니다.
  3. 사용이 끝나면 로그아웃(또는 접근 키)을 눌러 다음 사람이 내 부문으로 사용하지 않도록 합니다.

6문제 해결

증상확인할 것
인쇄를 보냈는데 나오지 않음비밀번호를 정확히 입력했는지, Mac은 사전 설정을 골랐는지 확인합니다. 복합기 패널의 작업 목록에서 거부 사유를 볼 수 있습니다.
인쇄 창에 "출력 방법" 또는 "인증/부문 관리"가 없음프린터가 AirPrint/일반 드라이버로 추가된 경우입니다. 프린터를 제거하고 신도 드라이버로 다시 추가합니다.
Mac 프린터 추가 시 SINDOH 드라이버가 목록에 없음드라이버 설치가 끝났는지 확인하고, Mac을 재시동한 뒤 다시 추가합니다.
Windows에서 인증/부문 관리 버튼이 흐리게 표시됨프린터 속성 → 구성 탭에서 부문 관리를 체크하거나 획득 설정을 누릅니다.
비밀번호를 잊어버림담당자에게 문의합니다.

해결되지 않으면 화면을 캡처해 담당자에게 보내주세요.
